# AtlasFold(-M) 特征接入 AR：给 T16 的摘要

来源：用户 2026-11-13 贴入的“AtlasFold-M 语言模型与折叠主干接入 AR：方案汇总”（原文依据 AR 项目的 T1/T2/T4/T6 map 与评测文件，其路径不在本仓库，原文链接在这里打不开）。以下为摘要，数字沿用原文，未重算；原文中的“出处”标签是 AR 项目里的 ticket 名。标有〔推断〕的是 desk 对“用于理解任务”的判断，不是原文结论。原文做的是结构预测（AR 生成复合物结构），本周训练目标是科学模态理解，两者不同。

## 1. 三层冻结特征（可复用的接口）
| 层 | 内容 | 输出 |
|---|---|---|
| AtlasLM-3B（48 block，每层 2304 维） | 每条链单独跑，无跨链 attention。7-tap：block 8/16/24/32/40/48 + final LN，RMS 归一，可学 softmax 加权 → LN → Linear(2304,1024) → GELU → Linear | 序列特征，进 AR 输入行（代替氨基酸词嵌入） |
| LM 模块（AtlasFold 的 run_lm_embedder + LMStack） | 49 层隐状态加权；48 层注意力 logits（36 头 → 128）求和；再过 4 个 PairBlock；复合物上 LMStack 跨整个复合物（链间 z 输入为 0，由 LMStack 自己产生） | s_lm [n,768]，z_lm [n,n,128] |
| 折叠主干（48 层 Pairformer，只跑 recycle 0） | s = s_init + proj_s_lm(s_lm)；z = outer(z_init) + rel_pos + proj_z_lm(z_lm) | 主干 s [n,384]，主干 z [n,n,128] |

## 2. 注入方式（当前配方 TRsz）
- 主干 s → 新 LN-Linear-GELU-Linear → 替换 AR 输入行。
- 主干 z → Linear(LayerNorm(z)) → 每头一个 bias，加在底座的全注意力层 logits 上（零初始化，lr ×10，不做 weight decay）。Qwen3.5-0.8B/2B 为 24 层，其中第 3/7/11/15/19/23 层是全注意力（8 头）；其余 18 层是线性注意力，没有注意力矩阵，无处加 bias。9B 为 8 层 × 16 头。
- 编码器、LM 模块、主干全部冻结；输入投影与 pair bias 投影训练；AR 从 Qwen base 起训。

## 3. 对理解有用的发现
| 发现 | 数字 | 范围 |
|---|---|---|
| 只靠逐链序列特征，链间关系学不到 | s_lm 进输入行，链 B 放不对：FoldBench 非 stacked 235 成功 0–10 个，朝向中位 122–139°，随机 132.3° | 单体/复合物权重、1k–13k 步均如此 |
| 主干 z 作 pair bias 后才学会 | 63–72/235（26.8–30.6%），朝向中位 48.8–68.5°；AtlasFold-M rank-1 110/235（46.8%），差 16–20 pp | 0.8B/2B/9B 同一接法，单 seed，raw 与 EMA 混用 |
| 模型确实在读链间 z | 把链间 z 置零，≤20° 从 131/225 掉到 4/225 | 仅在训练过的复合物类型上；干净集上泛化弱（R=.56/.73/.37 对应三个集合） |
| 更多 z 接法没有增益 | z 进输入、线性层旁加 z-bias 支路、链间 token：干净集 DockQ 差都在 ±.0076 内 | 2B，短分叉 |
| 链间信息在 z 里比在 s 里多 | 同一批残基对：主干 z 接触 AUC .97、top-k .93；主干 s .82、.70；LM 模块 z_lm 链间 AUC .795，s 界面残基 AUC .649 | cxval 166 落在 AtlasFold-M 训练期内，不是公平基线 |
| 链间信息随层数增长 | LMStack 把链间 z 从 AUC .50 提到 .80；主干第 12/24/48 层 .85/.86/.87 | |
| 模型越大，单链越好 | 单链 TM：0.8B .741，2B .730，9B .695（9B 与 2B 同步数 .646，配对差 +.049） | 注意 2B 对 9B 的比较步数不同 |
| 不值得训的部分 | 主干 recycle 3 轮：top-L/5 +.037，没过 +.03 门槛，耗时 ×3.4；再迭代冻结 LMStack 无用 | |

〔推断〕对序列理解：冻结序列编码器的逐层加权特征可以直接作为输入行接口；对 3D/复合物理解：需要 pair 级信息（z）才有链间关系，且 z 只能加在全注意力层——选底座要看全注意力层数。

## 4. 成本与风险
- 主干 R0 是 LM 编码器的 6.5 倍，换快速内核后约 4 倍；run2 每步里编码器约占 87%。
- 三角注意力 triton 内核在 H100 + triton 3.4 上算错（单算子误差 .93–.98），受影响的 run 作废或训练/评测编码器不一致；run2 起改用 cuEquivariance，后来 torch 2.10 / triton 3.6。
- 泄漏：AtlasFold 单体（PDB ≤ 2020-05）与 AtlasFold-M（≤ 2021-09-30）只按日期切分，未去同源。
- 状态：run3（2B）停在 u6749、9B 停在 u4655，都可续训，收尾评测未做；T4 暂停，T-O（八叉树加主干）已登记未启动。
