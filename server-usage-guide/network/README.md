# 出站代理

普通用户先读 [账号与登录](../users/user.md) 与 [存储与路径](../storage/user.md)，再读 [出站代理](./outbound-proxy.user.md)。

## 约定摘要

| 约定 | 为什么 |
|------|--------|
| 全员入口：`http://10.200.1.3:7890` | 单中心；枢纽与计算节点 `profile.d` 相同 |
| 枢纽进程监听 `0.0.0.0:7890` | 内网各节点连同一 IP:端口；客户端不要写 `0.0.0.0` |
| `/etc/profile.d/mihomo-proxy.sh` 注入代理变量 | 登录 shell 默认生效 |
| 禁止公网暴露 7890；计算节点不装 mihomo | 缩小攻击面，配置一处维护 |
| 默认上游：美国加州 VPS `23.106.159.223`（VLESS+REALITY） | 集群经枢纽出网；旧机 `23.106.154.45` 为备用 |

外网下载落盘路径见 [存储与路径](../storage/user.md)。
