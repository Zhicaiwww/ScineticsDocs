## 1. 命名空间

每节点本地 SSD 挂载为 `/data`、`/data0`（本机）。集群统一名为：

```text
/nas/nas1 … /nas/nasN
```

| 写法 | 含义 | 为什么 |
|------|------|--------|
| `/nas/nasN/...` | 跨节点稳定路径 | 脚本与多机任务路径一致 |
| 本机 `/data`、`/data0` | 当前节点本地盘入口 | 仅本机交互；禁止写入跨节点脚本 |

本枢纽对应关系（其它节点以本地 fstab / symlink 为准）：

| 本机 | NAS |
|------|-----|
| `/data0` | `/nas/nas1` |
| `/data` | `/nas/nas2` |

**默认共享根：`/nas/nas1/shared`**（本机盘即 `/data0/shared`）。

| 卷 | 用途 | 普通账号写 | 白名单写（`wzc`、`yjx`、`xdc`） |
|----|------|------------|--------------------------------|
| `/nas` 根及未列出的子树 | 命名空间 | 否 | 否 |
| nas1 除 `shared` 外 | — | 否 | 否 |
| nas1 `shared` | 共享缓存与中小规模公共数据 | 是 | 是 |
| nas2–nas7 | 超量数据 | 否 | 是 |
| nas8 除本人 `$HOME` 外 | — | 否 | 否 |
| nas8 `$HOME` | 家目录；轻度个人使用 | 是（仅本人） | 是（仅本人） |

日常代码、环境与缓存只写 nas8 家目录与 nas1 的 `shared`。枢纽 `/data` 为 nas2，仅白名单可写。

## 2. 保存位置约定

| 内容 | 路径 | 为什么 |
|------|------|--------|
| 个人代码、环境、实验、配置 | `$HOME`（=`/nas/nas8/users/<name>`） | 统一保存在 nas8 用户卷 |
| 共用数据 / 权重 | `/nas/nas1/shared/datasets`、`.../models` | 钉死约定卷 |
| 下载缓存（HF 等） | `/nas/nas1/shared/huggingface` 等 | 减少重复下载 |
| 登录 token | `$HOME/.config/...` | 凭证不进共享树 |
| `/data` 或 `/nas/nasN` 根下个人项目 | 禁止新建 | 根目录保留给盘结构与约定树 |
| 超量原始数据、占空间中间结果 | `/nas/nas2` … `/nas/nas7`（须在写白名单内） | 避免撑满 nas1 / nas8 |

共享相关环境变量使用 **`/nas/nas1/...`**（见 [user.md](./user.md)）。

## 3. 禁止非法软链

`/data`、`/data0`、`/nas/nasN` 表示**一块盘**。下列软链（及同名实目录）一律禁止：

| 禁止 | 说明 |
|------|------|
| 盘根下名为 `data` / `data0` 的目录或软链 | 例如 `/data/data -> …`、`/nas/nas2/data0 -> …`，与盘名冲突 |
| 在非约定卷上伪造 `shared` 入口 | 例如在 `/nas/nas2/` 下再建 `shared` 指向别处，造成「共享在哪块盘」歧义 |
| 用软链把 A 盘路径伪装成 B 盘路径 | 跨 `nasN` 指鹿为马；作业与排障会读错卷 |

```text
# 禁止示例
/data/data -> /data/<user>/...
/data/data0 -> …
/nas/nas2/shared -> /data0/shared     # 共享只认 nas1，禁止在 nas2 根下挂 shared
/nas/nas3/data -> …
```

**允许：** 人名、项目名作为盘根子目录；脚本与文档写完整路径 `/nas/nas1/shared/...` 或 `/nas/nasN/<project>/...`。

**为什么：** 软链一旦与盘名或约定共享根同名，路径语义崩溃（`/data/data/...`、误以为每块盘都有独立 `shared`）。
