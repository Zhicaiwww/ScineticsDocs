## 约定摘要

| 约定 | 为什么 |
|------|--------|
| 要登录的节点均已开同一套账号，同一登录名同一 UID/GID | 共享盘按数字鉴权；换节点不必改权限 |
| 日常 SSH 用本人账号；用户钥不能登 root | root 与用户钥匙分开 |
| 资源看板与本文同站 | 占用与分配见 [资源看板](/) |
| `$HOME` 在用户盘 nas8 上，含代码、环境与个人数据 | 各节点看到同一棵家目录，不必拷贝 |
| 一人一账号；身份以 UID / `USER` 为准 | 权限与审计跟人绑定 |
| `$HOME=/nas/nas8/users/<name>`，模式 `755` | 本人可写；**其它用户可读不可写** |
| `/nas` 默认可读；普通账号仅可写共享盘 `shared` 与本人 `$HOME` | 防止误写公司专用盘与盘根 |
| 白名单额外可写公司专用盘 nas2–nas7（`wzc`、`yjx`、`xdc`） | 大体积数据与日常路径分离 |
| `data-workspace.sh` 仅导出路径 | 开户与 chmod 显式执行 |

开户时写入主组（与用户同名）及附加组 `lab`(2000)、`video`(44)、`render`(109)。`ls` 在某节点把家目录属主显示成数字，表示该节点尚未开这个户，不是磁盘损坏。
